# 購買申請システム(PRQ)画面設計書(抜粋)

| 項目 | 内容 |
|---|---|
| 文書番号 | PRQ-SCR-001 |
| 版数 | v1.4 |
| 最終更新 | 2026-07-03 |
| 関連文書 | PRQ-BD-001(基本設計書 v2.0) |

主要5画面のみを抜粋する。SCR-07(代理承認者設定)・SCR-08(月次締め)は詳細設計で確定する。

## SCR-01 申請一覧

### 表示項目

| 項目 | 内容 |
|---|---|
| 申請番号 | `PRQ-YYYY-NNNNN` |
| 件名 | 申請の件名 |
| 申請者 | 氏名(所属部門) |
| 税抜合計金額 | 明細の数量×単価の合計 |
| 状態 | 表示名(基本設計書 §2) |
| 対応待ち | 次に対応すべき担当者の氏名。`draft`・`closed`・`canceled`・`expired` は「—」 |
| 更新日時 | 最終更新日時 |

### 絞り込み

- 状態(複数選択)、申請期間、申請者、部門、金額範囲
- 既定の絞り込み: 自分が申請者または対応待ちの申請のみ
- 承認者は自部門の申請のみ検索できる。購買担当・経理担当は全部門を検索できる

## SCR-02 申請登録・編集

### 入力項目

| 項目 | 必須 | 制約 |
|---|---|---|
| 件名 | ○ | 60文字以内 |
| 希望納期 | ○ | 当日以降の日付 |
| 購買理由 | ○ | 500文字以内 |
| 予算科目 | ○ | 申請者の所属部門に紐づく科目から選択 |
| 明細:品目名 | ○ | 100文字以内。1申請あたり20明細まで |
| 明細:数量 | ○ | 1以上の整数 |
| 明細:単価 | ○ | 税抜。1円単位。0円は不可。上限 9,999,999円 |
| 添付ファイル | — | 見積書等。5MBまで、5件まで |

### ボタン

| ボタン | 活性条件 | 動作 |
|---|---|---|
| 一時保存 | 常時 | `draft` で保存する |
| 提出 | 必須項目がすべて充足 | 確認ダイアログの後、`submitted` にする |
| 削除 | 状態が `draft` | 申請を物理削除する |

## SCR-03 申請詳細

### 表示項目

- 申請ヘッダ(申請番号・件名・申請者・状態・希望納期・購買理由・予算科目・税抜合計金額)
- 明細一覧(品目名・数量・単価・金額・検収数量)
- 承認履歴(承認ステップ・承認者・承認日時・差戻し理由)
- 発注情報(サプライヤ・発注単価・発注日・EDI送信日時)
- 検収情報(検収日・検収者)

### ボタン

| ボタン | 表示ロール | 活性条件 |
|---|---|---|
| 編集 | 申請者 | 状態が `draft` または `returned`、かつ本人の申請 |
| 取消 | 申請者 / 購買担当 | 状態が `draft` / `submitted` / `returned` / `approved` / `ordered` |
| 検収登録 | 申請者 | 状態が `ordered`、かつ本人の申請 |
| 複製して新規申請 | 全ロール | 常時 |

取消ボタンの押下時は「この申請を取り消します。よろしいですか」の確認ダイアログを表示する。

## SCR-04 承認処理

### 表示項目

- 申請詳細(SCR-03 と同じ)
- 承認コメント入力欄(差戻し時は必須、承認時は任意)

### ボタン

| ボタン | 活性条件 |
|---|---|
| 承認 | 状態が `submitted`、かつ自分が現在の承認ステップの担当者 |
| 差戻し | 状態が `submitted`、かつ自分が現在の承認ステップの担当者、かつ承認コメントが入力済み |

二段階承認の場合、一次承認の完了後に状態の表示名を「一次承認済」に切り替える。

## SCR-05 発注処理

### 入力項目

| 項目 | 必須 | 制約 |
|---|---|---|
| サプライヤ | ○ | サプライヤマスタから選択 |
| 発注単価 | ○ | 明細ごと。税抜。申請単価と異なってよい |
| 発注日 | ○ | 当日を既定とする |

### ボタン

| ボタン | 活性条件 | 動作 |
|---|---|---|
| 発注確定 | 状態が `approved` で、サプライヤと全明細の発注単価が入力済み | `ordered` にし、EDI送信の対象にする |

発注単価の合計が申請の税抜合計金額を超える場合は、警告を表示したうえで確定を許可する。

## SCR-06 検収登録

### 入力項目

| 項目 | 必須 | 制約 |
|---|---|---|
| 検収日 | ○ | 当日を既定とする。未来日は不可 |
| 明細:検収数量 | ○ | 0以上の整数。発注数量以下 |
| 検収コメント | — | 200文字以内 |

### ボタン

| ボタン | 活性条件 | 動作 |
|---|---|---|
| 検収登録 | 状態が `ordered` | `received` にする |
